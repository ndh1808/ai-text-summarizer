Artificial intelligence is increasingly used to support education and scientific research. Generative AI systems can produce new text based on user instructions and a source document. Text summarization is one example of this capability. A user supplies an article and asks the model to preserve the most important ideas in fewer words. The quality of an automatically generated summary depends on the original text, prompt design, and model behavior. Summaries are useful for scanning large collections of documents, but they should not replace checking the original source. A good system must make it easy to review the results and understand potential limitations. Developers can build a small web application using Python and Streamlit. The application sends a prompt to a model provider and displays the generated response. An evaluation should assess accuracy, key-idea coverage, and readability rather than relying only on output length.
